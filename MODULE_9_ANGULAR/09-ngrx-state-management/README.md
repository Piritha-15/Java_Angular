# Angular Hands-On 09-ngrx-state-management

## Objective
Actions, reducers, selectors, effects, immutable state and Redux DevTools.

## Run
This folder contains the main source implementation for the hands-on. To run it inside a generated Angular workspace:

```bash
ng new student-course-portal --routing --style=css
# copy the src/app files from this folder into the generated project
npm install
ng serve
```

Open: http://localhost:4200
